Frequently Asked Questions

What is the difference between Retail Pro and Cloud ERP?
Retail Pro is an offline, single-terminal POS. It costs $199 once and works without internet. Cloud ERP is a custom-quoted solution for multi-location businesses that need live data sync, multi-branch support, and e-commerce integrations.
Why is Cloud ERP not priced on the website?
Cloud ERP is tailored to each business. The number of branches, users, warehouses, and modules changes the scope — so we quote individually. You get a one-time license fee plus a monthly cloud fee that matches exactly what you need. No paying for features you don't use.
Is there a contract for Cloud ERP?
No long-term lock-in. The one-time fee covers setup and licensing. The monthly cloud fee can be canceled anytime — your data is exportable and stays yours.
What hardware do I need for Retail Pro?
Any Windows laptop, a standard USB barcode scanner, and an ESC/POS thermal receipt printer. We do not lock you into buying special hardware—you can use whatever you already have in your shop.
Can I use the Cloud ERP on multiple devices?
Yes! Cloud ERP supports multiple device access on desktop, web browsers, and mobile phones, with real-time data sync across all your locations.
